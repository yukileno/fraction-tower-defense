## 🏰 ゲームのルール & 特徴

### 1. タワーディフェンス形式の白熱バトル
- 道に沿ってモンスターたち（スライム、ゴブリン、コウモリ、ゴーレム、大魔竜ドラゴン）が防衛タワーと城へ迫ってきます。
- **城に一番近い先頭のモンスターがターゲット**になり、そのモンスターが持つ「分数の計算問題」が画面下に大きく表示されます。
- 問題を解くと、タワーの魔導士から魔法弾が発射され、モンスターを撃破！
- モンスターが城に到達すると城が攻撃され、**ライフが1つ減少**します（初期ライフ: ❤️❤️❤️ 3つ）。
- ライフが0になるとゲームオーバーです。

### 2. 連続正解（コンボ）とハイスコアシステム
- 連続して正解すると **コンボボーナス（x1.2, x1.5, x2.0...）** が発生し、スコアが大幅にアップ！
- すばやく解くほど「タイムボーナス」が加算されます。
- 最高スコア（ハイスコア）はブラウザに自動保存されます。

### 3. 必殺技（MPゲージ）システム
- 正解するたびにMPが25%たまります。
- ❄️ **タイムフリーズ（消費MP 50）**: 8秒間、全モンスターの進行を極限までストップ！じっくり通分の計算ができます。
- 🔥 **メテオボム（消費MP 100）**: 先頭の厄介なモンスターを一撃で粉砕します。

## 📚 小学校5年生の算数教育に特化した親切設計

### ① 通分の3大パターンを完全網羅
1. **倍数関係（レベル1）**: 一方の分母が他方の倍数（例: $\frac{1}{2} + \frac{1}{4}$ → 4にそろえる）
2. **互いに素（レベル2）**: 分母同士のかけ算でそろえる（例: $\frac{1}{2} + \frac{1}{3}$ → 6にそろえる）
3. **最小公倍数が積より小さい（レベル3・重要単元）**: 4と6→12、6と8→24 など、5年生がつまずきやすいパターンを重点出題。
4. **約分マスター（レベル4）**: 答えが $\frac{2}{4}$ や $\frac{4}{6}$ になり、約分が必要な問題。
5. **ボス級（レベル5）**: 帯分数やくり下がりのある引き算（例: $1\frac{1}{3} + 1\frac{1}{2}$, $2\frac{1}{4} - \frac{3}{4}$）。

### ② 「約分忘れ」に対するやさしいアシスト判定
- 5年生が最もやりがちな「通分と足し算は合っているのに、最後の約分を忘れる」ミス。
- 本作ではこれを**即ミス・ダメージにせず**、「惜しい！約分できるよ！（2で割ってみよう）」とメッセージを出して再入力を促します。子どもたちのやる気を削がず、約分の習慣づけをサポートします。

### ③ よくあるミスを自動診断
- **分母同士を足し算してしまった場合**: 「分母同士を足しちゃダメ！まず通分して分母をそろえよう！」と警告。
- **分子に倍数をかけ忘れた場合**: 「分母を大きくしたとき、分子にも同じ数をかけるのを忘れてないかな？」とアドバイス。

### ④ 📝 手書き計算メモ（スクラッチパッド）内蔵
- 画面右上の「📝 計算メモ」ボタンを押すと、画面上に手書きできるキャンバスが出現。
- タブレットの指やタッチペン、PCのマウスで、倍数のメモやひっ算を自由に書き込めます。

### ⑤ 📖 「通分・約分のコツ」ガイド & 📚 復習ノート
- ゲーム中いつでも「📖 コツ」ボタンで、通分のやり方をイラスト付きで確認可能。
- ゲームオーバー後には、出題された全問題の「通分の最小公倍数」「途中式」「答え」をまとめた**復習ノート**が表示され、振り返り学習ができます。

## ⌨️ 操作方法

- **マウス / タッチ操作**:
  - 画面上の大きなテンキーで数字を入力
  - 「切替 ⇄」ボタンで分子・分母を移動
  - 「まほうこうげき！ (決定)」で解答送信
  - 「帯分数で答える」ボタンで整数入力枠を表示
- **キーボード操作**:
  - 数字キー `0`〜`9`: 数字入力
  - `/` または `Tab` または `↓`: 分子から分母へ移動
  - `↑`: 分母から分子へ移動
  - `Enter`: こうげき（解答決定）
  - `Backspace`: 1文字消去
  - `F` キー: タイムフリーズ発動
  - `M` キー: メテオボム発動
